This project is a global health data dashboard that visualizes data trends, rankings, and correlations based off select indicators from WHO and OWID. In order to use it, the user can either manually toggle and enter specific indicators, countries, years, or other data they want to see, or they can prompt the chat to change the graph/dashboard.
I'm most proud of the additional chat feature as it adds a layer of easier usability as opposed to just being able to manually zoom in or toggle the graph.

To run it locally you can either use the render link: https://health-data-dashboard-21rw.onrender.com or deploy from Github Pages: https://izzyh-gif.github.io/Health%20Data%20Dashboard/

A private API Key is used for the OpenAI API key for chatting functionality, and is hidden from git commits using .gitignore, stored in back-end, and therefore kept secret.

I used the model GPT 5.6 Luna with Kiro as my IDE. I used AI in this project mainly to help create the data visualizations and analysis as I didn't have as much prior experience in data analysis in Python. Because I had more prior experience using the OpenAI API key on previous projects, I was able to customize and edit more significantly on my own in this part for this project.
